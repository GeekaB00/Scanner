Use Chrome or Edge on desktop — this browser has no Web Serial. This page must be opened over HTTPS.
  1. Choose your board above, then connect it with a USB data cable.
  2. Click FLASH FIRMWARE and pick the serial port (CH340 / CP210x).
  3. If it won't connect: hold BOOT, tap RST, release BOOT, and try again.
  4. After flashing, press RST — the Geek Scanner boot image appears — tap the screen to start scanning.
  5. 3.5" boards: on the first start, tap the crosses to calibrate touch.
